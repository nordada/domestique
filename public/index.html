Reseed from library

Drop a .torrent file for something your tracker says needs seeds. This checks whether its content already exists somewhere in your library under a different name (by exact file size), then - once you confirm - stages it into the exact layout the torrent expects and hands it to Transmission, paused, to verify and reseed. Matching here is size-only and can be wrong; Transmission's own piece-hash verify after Stage & hand off is what actually confirms a real match, so always Preview first and check the verify percentage afterward. Drop more than one .torrent at once to queue them: a torrent that matches completely stages and hands off automatically, one at a time; anything partial pauses the queue for your call before moving on.

Generates a Plex poster (poster.jpg) for a show once it has an uploaded logo (see the Events tab), since most niche races aren't recognized by Plex's own metadata agents. Purely opt-in per show - a show with no logo is left alone entirely, no placeholder poster is generated for it. These colors are independent of the accent color above - that's this web UI's own theme; this art is what shows up inside Plex.

Transmission status check

Drives the header icon's glow with what your torrents are actually doing, not just whether Transmission is reachable: green when everything's idle/seeding with no errors, amber while something's downloading, red if any torrent has a tracker or local error. Unrelated to the webhook Transmission already sends this app on torrent completion.

External indexer

Bookmarks the race indexer/tracker site this instance sources torrents from. Unlike the other header icons, clicking it opens the site itself in a new tab instead of jumping here, and it shows that site's own favicon with an accent ring once a URL is set. The glow layers on top of that once reachability is known: green while the site's responding, red if a check finds it down. Checked on its own heartbeat below rather than the general status-poll interval, so a single slow response doesn't flicker the glow.

Reseed from library

Where staged (hardlinked, falling back to copied when necessary) files live before being handed to Transmission - see the Reseed tab. Defaults to a hidden folder inside your library root, which also guarantees hardlinking actually works (same filesystem/device as the library itself). Only override this to point at a separate volume instead - trading that hardlink guarantee for isolation. If you do, this path must also be bind-mounted read-write into Transmission's own container at this exact same path, or Transmission will report 0% verified even on a perfectly good match.

Webhook security

/webhook/torrent-done (what Transmission's hook script calls) has no other authentication of its own: it's meant to be reached only by that script, trusted implicitly on your LAN. Set a secret here if that route is ever reachable from outside your LAN, e.g. behind a reverse proxy or a Cloudflare Tunnel, and put the same value in torrent-done.env's WEBHOOK_SECRET so the hook script keeps working. Leave blank to keep the original open behavior.

Login lockout

Basic Auth (the password prompt for this whole site) has no built-in brute-force protection, so this app adds its own: after this many wrong-password attempts in a row, further attempts are rejected for a cooldown instead of even being checked. The cooldown clears itself automatically (no restart needed) and doubles each time it's triggered again right after expiring, up to a 30-minute cap, then resets to the base once a login actually succeeds.
